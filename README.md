# 🌐 Adarsh Gajanan Dutonde - Personal Portfolio Website

Official personal portfolio repository of **Adarsh Gajanan Dutonde**, First Year B.Tech Data Science Student at **DY Patil College of Engineering and Technology, Kolhapur**. Aspiring Data Analyst & Future AI/ML Engineer.

---

## 🚀 Key Features

* **4 Dynamic Color Themes**:
  * 🖤 **Dark Black (Default)**: Pitch black (`#07080b`) with neon cyan and azure glow.
  * 💜 **Purple Dark**: Cyberpunk midnight violet (`#090514`) with electric magenta accents.
  * 💙 **Blue Dark**: Deep space navy (`#030814`) with sapphire and sky blue accents.
  * 🤍 **Light Theme**: Clean executive slate (`#f8fafc`) with deep indigo accents.
  * *Theme selection persists across page refreshes via `localStorage`.*
* **Interactive Constellation Canvas**: HTML5 Canvas particle network that connects nodes and repels on cursor proximity, dynamically adopting theme colors.
* **3D Perspective Tilt**: Interactive card tilt effect responding to cursor coordinates on projects, statistics, and certificate cards.
* **Typing Animation Engine**: Dynamic cycling through core competencies and focus areas.
* **Vertical Education Timeline**: Highlighting B.Tech in Data Science at DY Patil College of Engineering and Technology, Kolhapur.
* **Interactive Skills Matrix**: Categorized skill grid with filter tabs (*Programming*, *Data Science & AI*, *Web Tech*, *Tools*) and animated progress bars.
* **Featured Projects**:
  * 🌾 **AgroVision AI**: Smart Agriculture intelligence & crop recommendation platform.
  * 🌿 **FarmGuard AI**: Computer Vision-based precision crop disease detection.
  * 📊 **Student Placement Prediction System**: ML predictive model evaluating student placement likelihood.
  * 🔄 **PortRepo Collab**: Real-time GitHub-to-Portfolio project synchronization system.
* **Verified Credentials**: High-resolution certificate modal viewer for Python, Data Science, Machine Learning, and Web Development.
* **GitHub Activity Section**: Simulated 52-week activity heatmap with hover tooltips and metrics.
* **Client-Side Validated Contact Form**: Interactive glassmorphism contact card with real-time field validation and toast notifications.

## 🛠️ Built With

* **HTML5**: Semantic markup, OpenGraph tags, Schema.org JSON-LD.
* **CSS3**: Vanilla CSS Custom Properties, Glassmorphism, CSS Grid & Flexbox, Fluid Typography.
* **Vanilla JavaScript (ES6+)**: Custom particle engine, theme switcher, IntersectionObserver animations, modal dialogs, and input validation.
* **Feather Icons**: Modern, clean iconography.

## 💻 Local Setup & Development

To preview or run this portfolio locally:

```bash
# Clone the repository
git clone https://github.com/adarshdutonde18/portfolio.git

# Navigate into the project directory
cd portfolio

# Start the built-in static server
node server.js
```

Open your browser and visit: `http://localhost:3000`
